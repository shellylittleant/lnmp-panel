# 09 默认不做功能说明

> 记录日期：2026-09-16
> 状态：已确认，2026-09-16
>
> 结论：定时任务、数据库管理做进核心；WebSSH 不做且不做插件；文件上传下载作为官方插件优先开发；其余不做。
>
> 2026-09-17 修订：需求方实测后要求文件管理为刚需，改为**核心功能、全目录**，见 [17-文件管理与手动证书.md](17-文件管理与手动证书.md)。上传下载插件退役。

这些是宝塔面板具备、而你的需求描述里没有提到的功能。我默认不放进核心，逐项说明它是什么、为什么不做、以及它与"面板不设限"理念是否冲突。

| 功能 | 是什么 | 默认不做的原因 | 与理念的关系 | 我的倾向 |
|---|---|---|---|---|
| 文件管理器 | 在浏览器里浏览、上传、下载、在线编辑服务器文件，改权限 | 界面工作量大；以 root 身份对外暴露任意文件读写，是面板最大的攻击面之一；任何 SFTP 客户端都能替代 | 有冲突："SSH 能做的面板都能做"，文件操作是最典型的一项 | 核心不做，作为官方插件候选，需要的人装 |
| WebSSH 在线终端 | 浏览器里打开一个 root 终端 | 等于把 root shell 挂在网页上，安全风险极高；你本来就有 SSH | 有冲突，理由同上 | 核心不做，官方插件候选 |
| 定时任务管理 | 可视化编辑 cron，定时跑脚本、备份 | 你没提到。但证书续期、日志统计、备份本身就需要内部调度器 | 无冲突 | **建议做进核心**，成本很低，调度器反正要写 |
| 邮件服务 | 安装管理 Postfix/Dovecot 收发邮件服务器 | 完全不是 LNMP 范畴；邮件服务器涉及反垃圾、DNS、IP 信誉，维护成本极高 | 无冲突 | 不做，也不建议做插件 |
| FTP 服务 | 安装管理 vsftpd | 明文协议，已被 SFTP 淘汰；SSH 自带 SFTP | 无冲突 | 不做 |
| Docker 管理 | 容器与镜像管理 | 不是 LNMP 范畴；Docker 会自己改写防火墙规则，与面板独占 nftables 的设计直接冲突 | 无冲突 | 不做，明确不支持与 Docker 共存 |
| 软件商店 | 一键安装 WordPress、Redis、Memcached 等 | 这正是宝塔臃肿的来源；插件机制就是它的替代品 | 无冲突 | 不做商店本身；Redis 等 PHP 常用配套作为官方插件提供 |

## 补充一项之前没列的

| 功能 | 是什么 | 建议 |
|---|---|---|
| 数据库管理 | 建库、建用户、改密码、导入导出 | 建站必然要建库，**建议做进核心**，只做这几项，不内嵌 phpMyAdmin |
