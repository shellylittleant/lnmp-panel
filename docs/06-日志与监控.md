# 06 日志与监控

> 记录日期：2026-09-16
> 状态：需求已确认，细节为我的建议

## 需求

监控的本质是**日志的统计与可视化**。把日志功能做完善，统计只是从日志提取数据的过程。

## 日志来源

| 类别 | 来源 |
|---|---|
| 服务器日志 | journald / syslog、auth.log（SSH 登录尝试）、内核日志、nginx error.log、php-fpm error log、MySQL error log 与慢查询日志、防火墙丢包日志 |
| 网站运行日志 | 每个站点独立的 nginx access.log、error.log、PHP 错误日志 |

## 功能形态

1. **日志查看**：按来源、站点、时间范围、关键字、级别筛选，实时跟随。
2. **日志统计**：从 access.log 提取 PV、UV、状态码分布、响应时间、热门 URL、来源 IP、Referer、User-Agent；从 auth.log 提取 SSH 失败尝试；从慢查询日志提取慢 SQL 排行。
3. **可视化**：按站点、按时间维度的图表。
4. **日志轮转与保留**：面板统一接管 logrotate 配置，保留周期可设。

## 待确认一处

CPU、内存、磁盘、网络流量这类**资源指标**不来自日志。采集成本很低（读 `/proc`），我默认作为一个基础面板页顺带做掉，不单独设计。如果你明确不要，告诉我。

## 存储

统计结果存在面板内嵌的 SQLite，原始日志留在磁盘上不搬动。不对接外部监控系统。
