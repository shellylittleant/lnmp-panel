# 03 核心理念与已确认决策

> 记录日期：2026-09-16
> 状态：已确认

## 核心理念（高于一切功能设计）

**可视化面板的目的是方便操作，不是限制操作。**
直接登录服务器能做的操作，面板都应该允许做到。面板只是让这些操作更快、更不容易出错。

推论：

1. 任何配置都提供**可视化表单**和**原文编辑**两条路，原文编辑是兜底，永远不封死。
2. 面板不能因为"界面上没有这个选项"就让用户去不了目标状态。
3. 面板要能容忍用户绕过面板手改文件，手改后面板要能正确读回，不能崩、不能覆盖。

## 模板机制（所有配置的统一形态）

所有配置项（nginx 站点配置、伪静态、301、SSL、php.ini、防火墙规则集等）统一采用**模板**形态：

- 面板内置一批**官方模板**（常见场景开箱即用）。
- 用户任何一次与现有模板不同的输入，即自动成为一个**新模板**，可命名、可复用、可导出。
- 模板本身也允许原文编辑。

这意味着"模板"是面板的核心数据结构之一，不是某个功能的附属。
