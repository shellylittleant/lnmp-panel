# 02 版本策略

> 记录日期：2026-09-16（第二次修订）
> 状态：已确认

## 原则："只设下限，拒绝旧版本"

不设最高版本，也不再纠结"保留三代"。初代版本只做一件事：**大幅提高最低支持版本**，低于下限的一律不支持、不兼容、不维护。

三代平滑过渡是否需要，后期再议。

## 版本下限

| 组件 | 最低版本 | 说明 |
|---|---|---|
| Ubuntu | 24.04 LTS | 只支持 LTS 版本（24.04、26.04 及以后），非 LTS 半年版不支持 |
| PHP | 8.2 | 2026-09-16 确认，由 8.0 提高到 8.2 |
| MySQL | 8.0 | 覆盖 8.0、8.4 LTS、9.x。注："10.x"是 MariaDB 的版本号，MySQL 没有 10，本项目只支持 MySQL |
| Nginx | 跟随 Ubuntu 源 | 不单独设限 |

下限以上的所有版本均支持，多版本 PHP 可共存、每站点各选。

## 备注

PHP 8.0、8.1 上游已停止安全更新，故下限定为 8.2。8.2 安全支持到 2026 年 12 月，届时视情况把下限提到 8.3。

## 软件来源

- PHP：Ondřej Surý PPA（Ubuntu 自带源只有一个 PHP 版本，无法多版本共存）
- MySQL：**按 CPU 架构分源**（2026-09-16 确认）。x86_64 用 MySQL 官方 apt 源，装 8.4 LTS；arm64 因官方源无包，用 Ubuntu 自带源的 mysql-server 8.0（Canonical 维护到 2029 年，在下限之内）。这是"拒绝兼容"原则的一个明确例外，原因是云上 ARM 机型已常见。官方源补齐 arm64 包后再统一。
- Nginx：Ubuntu 自带源
