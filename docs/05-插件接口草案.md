# 05 插件接口草案

> 对应 docs/08：**Go 编译期插件**。官方插件与核心同一仓库，build tags 控制是否编进去；正式发布二进制带全部官方插件，运行时可启停。第三方以 Go 源码提交合并，随官方发布。进程内无法降权，靠代码审查。
>
> docs/01 风险：接口定早了容易错。本文件是**草案**。阶段 1–7 核心按此形状挂钩子，允许小改并在报告里写明。**阶段 8 冻结**。冻结前不承诺第三方稳定。

## 1. 形态

插件是一个 Go 包，实现 `plugin.Plugin`，在 `init` 里 `plugin.Register`。

官方核心模块也实现同一接口中的钩子部分（至少 `ID`/`Hooks`），以便：

- 站点 PHP 版本下拉由 `site.php_versions` 钩子汇总（核心列出已装 ≥8.2，插件可追加旧版本支持——这是 docs/08 对插件的明确要求）。
- 菜单与路由同一套合并逻辑。

```go
package plugin

type Plugin interface {
    ID() string          // 稳定英文 id，如 filexfer
    Name() string        // 中文名
    Version() string
    Hooks() []Hook
    Routes() []Route     // HTTP，已处于鉴权之后
    Pages() []Page       // 声明式页面，核心渲染
    OnStart(ctx Context) error
    OnStop(ctx Context) error
}

type Hook interface {
    Name() string
    Handle(ctx Context, ev Event) (Result, error)
}

type Route struct {
    Method string
    Path   string // 相对 /api/v1/plugin/<id>/
    Help   string
}

type Page struct {
    MenuParent string // '', 'site', 'system' ...
    MenuTitle  string // 中文
    Path       string // 前端路由
    Schema     FormSchema // 声明式；复杂 UI 可改 StaticDir
    StaticDir  string     // 可选，嵌入静态页
}
```

`Context` 只暴露内部服务接口（Site、Nginx、Exec 白名单、Settings、Store 的插件专用 KV），不给 `*sql.DB`，不给任意命令。

## 2. build tags

| tag | 含义 |
|---|---|
| （无） | 只编核心，插件包不参与 |
| `plugin_filexfer` | 编入文件上传下载 |
| `plugin_all` | 全部官方插件。发布脚本用这个 |

插件文件头：

```go
//go:build plugin_filexfer || plugin_all

package filexfer
```

`plugins/register_stub.go` 无 tag，保证未选 tag 时工程仍能编译。

运行时：`plugins` 表 `enabled=0` 则不调用 `OnStart`、不挂 `Routes`/`Pages`。二进制里仍有代码。

## 3. 钩子清单（草案）

| 钩子名 | 何时 | 用途 |
|---|---|---|
| `menu.register` | 启面板 | 加菜单 |
| `site.php_versions` | 打开站点表单 | 追加 PHP 版本选项（旧版本插件） |
| `nginx.snippets` | 渲染 server 块 | 追加片段 |
| `template.official` | 启动 | 注册官方模板 |
| `scheduler.register` | 启动 | 注册内部 Job |
| `site.after_save` | 站点保存后 | 联动 |
| `firewall.sets` | 生成规则集 | 追加集合（仍由 firewall 统一 `nft -f`） |
| `settings.section` | 设置页 | 追加设置段 |

钩子失败不得让核心 panic；记录错误并在插件页展示。

## 4. 声明式页面

第一批官方插件以表单/表格/按钮为主，核心用同一套中文表单组件渲染 `FormSchema`（字段、类型、校验、提交打到插件 Route）。

允许 `StaticDir` 嵌入自有页面，但必须套路径前缀与会话 Cookie，禁止自己监听端口。

不做「插件写 Vue 源码热插」——编译期插件没有运行时前端构建。

## 5. 官方插件：文件上传下载

| 项 | 值 |
|---|---|
| ID | `filexfer` |
| 能力 | 选定已有路径上传覆盖或下载文件；可列出某一允许根下的一层目录以便选文件 |
| 允许根 | 默认仅 `/var/www/`；设置里可加站点根。禁止 `..`，禁止跟到 `/etc/lnmp-panel/secrets`、`panel.db`、私钥 |
| 不做 | 在线编辑、chmod、chown、删除目录树、解压、WebSSH |

这是 docs/09「文件上传下载做官方插件」的最小满足，不是文件管理器。

## 6. 明确拒绝的插件形态

- 外部进程 + socket（docs 未采用方案一）
- 运行时下载 `.so`（Go plugin 在静态/跨版本不稳定，不用）
- 闭源二进制丢进来（与选定方案冲突：必须源码合并）
- WebSSH 插件（docs/09：不做且不做插件）

## 7. 安全

- 插件与面板同进程、同 root。审查是唯一降风险手段。第三方进树必须审 `exec` 使用与路径拼接。
- 插件 HTTP 经同一 CSRF、同一审计（`plugin.<id>.<action>`）。
- 插件不能关闭审计、不能改 `admin` 表、不能提供删除 `audit_logs` 的路由（HTTP 层拦截路径）。
