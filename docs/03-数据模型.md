# 03 数据模型

存储：一块 SQLite，路径 `/var/lib/lnmp-panel/panel.db`，权限 0600。原始日志与站点文件不入库。

约定：

- 时间一律 UTC，`TEXT` 存 RFC3339。
- 布尔 `INTEGER` 0/1。
- JSON 数组/对象存 `TEXT`，由对应模块解析。
- 主键 `INTEGER AUTOINCREMENT`。
- 迁移表管理 schema，禁止启动时 `CREATE IF NOT EXISTS` 混用手工改表。

## 1. 迁移

```sql
CREATE TABLE schema_migrations (
  version INTEGER PRIMARY KEY,
  applied_at TEXT NOT NULL
);
```

阶段 1 写入 001 基础表（settings/auth/session/audit/plugin/templates）。后续阶段只追加新编号。

## 2. 面板与鉴权

```sql
CREATE TABLE settings (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);

CREATE TABLE admin (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  username TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  totp_secret BLOB,
  totp_enabled INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE TABLE sessions (
  id TEXT PRIMARY KEY,
  ip TEXT NOT NULL,
  user_agent TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  expires_at TEXT NOT NULL
);

CREATE TABLE login_attempts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ip TEXT NOT NULL,
  at TEXT NOT NULL,
  success INTEGER NOT NULL,
  username TEXT NOT NULL DEFAULT ''
);
CREATE INDEX idx_login_attempts_ip_at ON login_attempts(ip, at);

CREATE TABLE ip_locks (
  ip TEXT PRIMARY KEY,
  locked_until TEXT NOT NULL,
  reason TEXT NOT NULL
);

CREATE TABLE audit_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  at TEXT NOT NULL,
  ip TEXT NOT NULL,
  actor TEXT NOT NULL,
  action TEXT NOT NULL,
  resource TEXT NOT NULL DEFAULT '',
  detail TEXT NOT NULL DEFAULT '',
  request_id TEXT NOT NULL DEFAULT ''
);
CREATE INDEX idx_audit_at ON audit_logs(at);
CREATE INDEX idx_audit_action ON audit_logs(action);
```

`admin` 用 `CHECK (id = 1)` 保证单管理员。`audit_logs` 无删除路径。

`settings` 键（不完全列举，以代码常量为准）：

| key | 含义 |
|---|---|
| `bind_mode` | `public` / `localhost` |
| `ops_ip_cidrs` | JSON 字符串数组，运维白名单 |
| `listen_port` | 与引导配置同步展示 |
| `path_prefix` | 同上 |
| `metrics_raw_days` | 默认 7 |
| `metrics_hourly_days` | 默认 90 |
| `log_keep_days` | logrotate 默认保留 |
| `totp_suggested` | 是否已提示 |

引导配置 `/etc/lnmp-panel/panel.json` 只放启动必需：listen、path_prefix、tls 路径、db 路径、bind 地址。其余进 SQLite，避免两个来源打架。改端口/前缀/证书：写引导文件并提示重启。

## 3. 模板

```sql
CREATE TABLE templates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL,
  name TEXT NOT NULL,
  origin TEXT NOT NULL CHECK (origin IN ('official', 'user')),
  content TEXT NOT NULL,
  content_hash TEXT NOT NULL,
  parent_id INTEGER REFERENCES templates(id),
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  UNIQUE(type, content_hash)
);
CREATE INDEX idx_templates_type ON templates(type);
```

官方模板启动时从 embed 同步：按 `(type, content_hash)` upsert，不覆盖用户改名后的用户模板。用户删不掉 `origin=official`。

类型枚举见 `06-模板机制设计.md`。

## 4. 站点、证书、PHP、MySQL

```sql
CREATE TABLE sites (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  site_key TEXT NOT NULL UNIQUE,
  name TEXT NOT NULL,
  domains TEXT NOT NULL,              -- JSON 数组
  root TEXT NOT NULL,
  php_version TEXT,                   -- 如 '8.3'；静态站为 NULL
  nginx_template_id INTEGER REFERENCES templates(id),
  rewrite_template_id INTEGER REFERENCES templates(id),
  ssl_template_id INTEGER REFERENCES templates(id),
  raw_mode INTEGER NOT NULL DEFAULT 0,
  last_written_hash TEXT,
  enabled INTEGER NOT NULL DEFAULT 1,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE TABLE site_redirects (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id INTEGER NOT NULL REFERENCES sites(id) ON DELETE CASCADE,
  from_path TEXT NOT NULL,
  to_url TEXT NOT NULL,
  code INTEGER NOT NULL DEFAULT 301
);

CREATE TABLE certificates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id INTEGER REFERENCES sites(id),
  domains TEXT NOT NULL,
  issuer TEXT NOT NULL,
  cert_path TEXT NOT NULL,
  key_path TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  acme_account TEXT NOT NULL DEFAULT '',
  challenge TEXT NOT NULL DEFAULT 'http-01',
  created_at TEXT NOT NULL
);

CREATE TABLE php_versions (
  version TEXT PRIMARY KEY,           -- '8.2'
  installed INTEGER NOT NULL DEFAULT 0,
  extensions TEXT NOT NULL DEFAULT '[]',
  ini_template_id INTEGER REFERENCES templates(id),
  pool_template_id INTEGER REFERENCES templates(id),
  last_written_ini_hash TEXT,
  raw_ini_mode INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE mysql_databases (
  name TEXT PRIMARY KEY,
  charset TEXT NOT NULL DEFAULT 'utf8mb4',
  collate TEXT NOT NULL DEFAULT 'utf8mb4_0900_ai_ci',
  created_at TEXT NOT NULL
);

CREATE TABLE mysql_users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user TEXT NOT NULL,
  host TEXT NOT NULL DEFAULT 'localhost',
  created_at TEXT NOT NULL,
  UNIQUE(user, host)
);

CREATE TABLE mysql_grants (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES mysql_users(id) ON DELETE CASCADE,
  db_name TEXT NOT NULL REFERENCES mysql_databases(name),
  priv TEXT NOT NULL DEFAULT 'ALL'
);
```

域名唯一：保存站点时在应用层检查 `domains` JSON 与其他站点无交集。SQLite 不拆域名表，避免过度规范化；若查询不便，阶段 2 实现时**可以**加 `site_domains(domain PRIMARY KEY, site_id)` 作为索引表，属于实现细节，不改语义。

## 5. 防火墙、定时任务、插件

```sql
CREATE TABLE firewall_state (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  template_id INTEGER REFERENCES templates(id),
  raw_mode INTEGER NOT NULL DEFAULT 0,
  last_written_hash TEXT,
  last_applied_at TEXT,
  pending_backup TEXT,                -- 确认窗口内的回滚文件路径
  confirm_deadline TEXT
);

CREATE TABLE cron_jobs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  schedule TEXT NOT NULL,             -- 标准 cron 五段
  command TEXT NOT NULL,
  enabled INTEGER NOT NULL DEFAULT 1,
  last_run_at TEXT,
  last_status TEXT
);

CREATE TABLE plugins (
  id TEXT PRIMARY KEY,                -- 与插件 ID() 一致
  enabled INTEGER NOT NULL DEFAULT 1,
  config TEXT NOT NULL DEFAULT '{}'
);
```

系统 crontab 是真相源；`cron_jobs` 是面板托管的那一组。读盘对账，漂移则提示。面板内部 Job 不进此表，进代码注册表。

## 6. 监控与统计

```sql
CREATE TABLE metrics_raw (
  at TEXT PRIMARY KEY,
  cpu REAL NOT NULL,
  mem_used INTEGER NOT NULL,
  mem_total INTEGER NOT NULL,
  disk_used INTEGER NOT NULL,
  disk_total INTEGER NOT NULL,
  net_in INTEGER NOT NULL,
  net_out INTEGER NOT NULL,
  load1 REAL NOT NULL,
  extra TEXT NOT NULL DEFAULT '{}'    -- nginx/php-fpm/mysql 瞬时状态 JSON
);

CREATE TABLE metrics_hourly (
  bucket TEXT PRIMARY KEY,            -- 小时整点 RFC3339
  cpu_avg REAL NOT NULL,
  mem_avg INTEGER NOT NULL,
  disk_avg INTEGER NOT NULL,
  net_in_sum INTEGER NOT NULL,
  net_out_sum INTEGER NOT NULL,
  load_avg REAL NOT NULL
);

CREATE TABLE log_stats_hourly (
  bucket TEXT NOT NULL,
  site_id INTEGER,                    -- NULL 表示全局 / SSH / 慢查询
  kind TEXT NOT NULL,                 -- access|ssh|slowsql
  payload TEXT NOT NULL,              -- JSON：pv/uv/status/url/ip 等
  PRIMARY KEY (bucket, site_id, kind)
);
```

原始日志留在磁盘。统计结果可重建，丢了只影响图表。

## 7. 迁移与热备

```sql
CREATE TABLE pairing_tokens (
  token_hash TEXT PRIMARY KEY,
  expires_at TEXT NOT NULL,
  used_at TEXT
);

CREATE TABLE peers (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  address TEXT NOT NULL,              -- https://host:port/prefix
  role TEXT NOT NULL,                 -- migrate_target / ha_peer
  fingerprint TEXT NOT NULL DEFAULT '',
  last_seen_at TEXT
);

CREATE TABLE migrate_jobs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  peer_id INTEGER NOT NULL REFERENCES peers(id),
  phase TEXT NOT NULL,                -- handshake|preflight|full|incr|done|failed
  detail TEXT NOT NULL DEFAULT '',
  started_at TEXT NOT NULL,
  finished_at TEXT
);

CREATE TABLE ha_state (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  role TEXT NOT NULL CHECK (role IN ('standalone', 'master', 'standby')),
  peer_id INTEGER REFERENCES peers(id),
  term INTEGER NOT NULL DEFAULT 0,
  last_sync_at TEXT,
  last_scan_ms INTEGER NOT NULL DEFAULT 0,
  interval_sec INTEGER NOT NULL DEFAULT 60,
  lag_sec INTEGER NOT NULL DEFAULT 0,
  mysql_repl_ok INTEGER NOT NULL DEFAULT 0
);
```

任期 `term` 单调递增。自我保护比的是 term，大者为主。

## 8. 不入库的数据

| 数据 | 位置 |
|---|---|
| nginx / php.ini / nft / my.cnf / crontab 正文 | 系统路径，SQLite 只存模板 ID 与哈希 |
| 站点文件 | `/var/www/<site_key>/` |
| MySQL 业务数据 | MySQL 自己 |
| 证书 PEM | `/var/lib/lnmp-panel/tls/sites/` 或 `/etc/lnmp-panel/certs/` |
| 临时 SSH 钥 | `/var/lib/lnmp-panel/secrets/migrate-*`，用完删除 |
| 审计 | 在库中，但不允许删 |

## 9. 读回与对账

每个「面板会写的文件」在对应行上有 `last_written_hash`。GET 时读盘算哈希：

- 相同：界面展示表单值（由模板+变量还原）或上次原文。
- 不同：`drifted=true`，界面以磁盘原文为准，保存前不得用旧表单覆盖。

对账不进后台循环也可：阶段 2 起每次打开详情都读盘。热备与迁移在同步前强制对账一次。
