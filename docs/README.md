## 子目录

- `reports/<执行者名>/` 执行者的阶段报告
- `reviews/<执行者名>/` 审核者的审核结论

## 约定

- 每个决策一旦确认，回写到对应文档，并在文末标注确认日期。
- 未确认的问题保留在 01 文档的问题清单中，解答后移入对应设计文档。
- `docs/` 对执行 AI 只读，执行 AI 只能写自己的 `reports/` 子目录，代码只能写在项目根的 `work/<执行者名>/`。
