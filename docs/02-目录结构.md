# 02 目录结构

分两块：本仓库（`work/grok/`）目录，以及目标机上的目录（见 `00` 第 5 节，此处只列与仓库的对应关系）。

## 1. 仓库目录（阶段 1 起创建，阶段 0 仅有 docs/）

```
work/grok/
├── README.md
├── .gitignore
├── docs/                          # 架构文档（本阶段）
├── go.mod                         # 阶段 1
├── go.sum
├── cmd/
│   └── lnmp-panel/
│       └── main.go                # 只组装 app
├── internal/
│   ├── app/                       # 生命周期
│   ├── http/                      # HTTPS、路由、中间件
│   │   └── api/                   # 各资源 handler，按模块拆文件
│   ├── auth/
│   ├── audit/
│   ├── store/
│   │   └── migrations/            # SQL 迁移，按序号
│   ├── fs/
│   ├── exec/
│   ├── settings/
│   ├── scheduler/
│   ├── plugin/
│   ├── template/
│   │   └── official/              # 官方模板原文，go:embed
│   ├── env/
│   ├── site/
│   ├── nginx/
│   ├── ssl/
│   ├── php/
│   ├── mysql/
│   ├── firewall/
│   ├── logview/
│   ├── monitor/
│   ├── cron/
│   ├── migrate/
│   └── ha/
├── plugins/
│   └── filexfer/                  # 阶段 8，//go:build plugin_filexfer
├── web/                           # Vue 3 + TS + Vite
│   ├── package.json
│   ├── tsconfig.json
│   ├── vite.config.ts
│   ├── index.html
│   └── src/
│       ├── main.ts
│       ├── App.vue
│       ├── api/                   # 只封装 fetch
│       ├── router/

│       └── components/            # 表单、原文框、确认条
├── embed.go                       # //go:embed web/dist
├── scripts/
│   ├── install.sh                 # 目标机安装
│   └── uninstall.sh
├── systemd/
│   └── lnmp-panel.service
└── testdata/                      # 单元测试用模板与日志样本
```

约定：

- `internal/` 外不可引用领域包，插件通过 `internal/plugin` 的 Context 拿接口。
- handler 不得 import `internal/exec`、不得直接打开数据库。
- `web/` 构建产物只进 `web/dist/`，由 `embed.go` 嵌入。开发时 Vite 代理到后端，发布时无 node 运行时。
- 官方模板是文本文件，不是 Go 字符串散落。

## 2. 前端路由（均挂在路径前缀之下）

| 路由 | 页面 | 阶段 |
|---|---|---|
| `/login` | 登录（含 TOTP 第二步） | 1 |
| `/` | 概览：资源指标摘要、服务状态 | 1 壳 / 5 填数据 |
| `/sites` | 站点列表 | 2 |
| `/sites/:id` | 站点表单 + 原文 + 漂移提示 | 2 |
| `/templates` | 模板库 | 2 |
| `/ssl` | 证书列表 | 2 |
| `/php` | 版本、扩展、php.ini | 3 |
| `/mysql` | 库与用户、导入导出 | 3 |
| `/firewall` | 规则表单 + 原文 + 确认条 | 4 |
| `/logs` | 日志查看与统计图 | 5 |
| `/cron` | 定时任务 | 5 |
| `/migrate` | 配对与同步进度 | 6 |
| `/ha` | 角色、同步状态、启用主模式 | 7 |
| `/plugins` | 启停官方插件 | 8 |
| `/files` | 上传下载（插件关闭则无此路由） | 8 |

无前缀或前缀错误：后端直接 404，前端代码不会被下发。

## 3. 目标机目录与仓库产物对应

| 仓库 | 安装到 |
|---|---|
| 编译出的二进制 | `/usr/local/bin/lnmp-panel` |
| `systemd/lnmp-panel.service` | `/etc/systemd/system/lnmp-panel.service` |
| 运行时生成 | `/etc/lnmp-panel/`、`/var/lib/lnmp-panel/`、`/var/log/lnmp-panel/` |

安装脚本不把本仓库 docs 拷到目标机。

## 4. 命令白名单（`internal/exec`）

只允许下列可执行文件的绝对路径（Ubuntu 24.04 写死）：

| 路径 | 用途 |
|---|---|
| `/usr/bin/systemctl` | 启停重载服务 |
| `/usr/sbin/nginx` | `-t` 与 `-s reload` |
| `/usr/bin/apt-get` | 装软件（非交互 `DEBIAN_FRONTEND=noninteractive`） |
| `/usr/bin/add-apt-repository` | 加 PHP PPA（来自 `software-properties-common`，路径写死） |
| `/usr/bin/mysql` `/usr/bin/mysqldump` `/usr/bin/mysqladmin` | 库操作 |
| `/usr/sbin/nft` | 规则校验与加载 |
| `/usr/bin/rsync` `/usr/bin/ssh` `/usr/bin/ssh-keygen` | 迁移与热备 |
| `/usr/sbin/php-fpm8.2` 等 `/usr/sbin/php-fpm8.*` | `-t` 与重载（经 systemctl 优先） |
| `/usr/sbin/logrotate` | 手动触发 |
| `/usr/bin/crontab` | 用户任务 |

新增命令必须在阶段报告里说明。禁止调用 `docker`、`ufw`、`iptables`、`pecl`、`apache2`。
