# 14 界面结构

> 记录日期：2026-09-17
> 状态：已确认（需求方在阶段 6 审核期间提出）

## 原则

所有"装东西"的动作集中在一个地方，叫**环境安装**。用户不应该在网站页装 Nginx、在 PHP 页装 PHP、在数据库页装 MySQL。功能页只管用，不管装。

## 主菜单（十项，顺序固定；2026-09-17 增加"文件"）

| 菜单 | 内容 |
|---|---|
| 概览 | 资源指标、服务状态、环境状态卡片（Nginx / PHP 各版本 / MySQL 是否已装，未装时给"去环境安装"入口） |
| 网站 | 站点列表与详情：域名绑定、根目录、PHP 版本选择、nginx 配置表单与原文、伪静态、301、SSL；页签"模板库" |
| 文件 | 全目录文件管理，默认打开 /var/www，详见 docs/17 |
| 数据库 | 库、用户、导入导出、my.cnf |
| 防火墙 | 规则表单与原文、确认窗口、封禁 |
| 日志 | 来源查看、跟随、统计、轮转配置 |
| 定时任务 | crontab 可视化、内部任务只读列表 |
| 迁移与热备 | 配对、预检、全量与增量同步、热备角色与切换（阶段 7 并入同一页，两个页签） |
| 设置 | 面板设置、白名单、密码与 TOTP、会话；页签"环境安装" |
| 审计 | 审计日志查询 |

## 环境安装（设置下的页签，概览卡片可直达）

分两块：

1. **环境**：Nginx 安装；PHP 源、各版本安装与卸载、每个版本的扩展与 php.ini、pool；MySQL 安装（按架构分源）、状态。
2. **插件**：阶段 8 的官方插件启停与配置。

## 去掉的入口

- 网站页的"从 Ubuntu 源安装 Nginx"按钮：站点未装 Nginx 时，网站页显示一句提示并链接到环境安装。
- 独立的 PHP 菜单：内容并入环境安装。
- 数据库页的"从官方源安装 MySQL"按钮：同上，提示并链接。
- 独立的迁移菜单、热备菜单：合并为"迁移与热备"。
- 独立的插件菜单：并入环境安装。
- 独立的模板菜单：并入网站页签。

## 对后端的影响

无。所有 HTTP API 保持不变，只改前端路由与页面组织。
