# 00 产品原则

> 记录日期：2026-09-16
> 状态：已确认（来自首次需求讨论）

## 定位

一个面向 LNMP 站点运维的 Linux 后台控制面板。对标宝塔面板，但只做宝塔功能的一个小子集，拒绝臃肿。

## 核心原则

1. **简单**：功能少而精，界面直接，不做用不到的东西。
2. **专一**：只服务 LNMP 场景，不服务其他技术栈。
3. **避免生态兼容**：不兼容旧版本、不兼容多发行版、不兼容多种同类软件。版本组合固定，省掉所有兼容性代码。
4. **扩展靠插件**：核心之外的需求一律以插件形式实现，核心不膨胀。

## 固定技术栈（只支持高版本）

> 2026-09-16 修订："只支持最高版本"改为"只设下限、拒绝旧版本"，详见 [02-版本策略.md](02-版本策略.md)。

| 组件 | 约束 |
|---|---|
| 操作系统 | Ubuntu，只支持最新版本，不做低版本适配 |
| Web 服务器 | Nginx |
| 数据库 | MySQL（版本待确认，只支持高版本） |
| PHP | 8.0 及以上 |

## 核心功能范围（仅此几项）

1. **系统一键迁移**：站点整体从一台服务器迁移到另一台。
1a. **容灾热备**（2026-09-16 新增）：主备两机近实时同步，故障切换与恢复回切。
2. **防火墙配置**：端口开放与封禁。
3. **监控与数据统计**：系统资源与服务状态监控。
4. **基础网站配置**：建站、301 跳转、伪静态等，本质是对 nginx conf 的可视化管理。
5. **PHP 管理**：扩展加载等基础配置。

## 明确不做

- 多发行版支持（CentOS、Debian 等）
- 旧版本 PHP / MySQL / Ubuntu
- Apache、OpenResty、PostgreSQL 等同类替代软件
- 宝塔式的应用商店、大而全的功能矩阵
