# 13 真机部署与测试指南

> 写给需求方本人，用面板界面操作为主，只有几步要在服务器上敲命令。
> 对应代码：`work/grok` commit `594e883`（真机第一轮修复后）。程序包：`发布/lnmp-panel-amd64.tar.gz`（x86_64 专用）。
> grok 那份 `docs/reports/grok/真机验证清单.md` 是给 AI 用 API 跑的，你不用看。

## 一、准备

| 项 | 要求 |
|---|---|
| 服务器 | x86_64，Ubuntu 24.04，全新系统，不装 Docker，测完可以重装 |
| 网络 | 公网 IP；云安全组放行 22、80、443，以及 20000 到 49151 整段（面板端口随机落在这个范围） |
| 域名 | 一个测试域名，A 记录指到这台机器，用来测真证书 |
| 本机 | 能 ssh 和 scp 到服务器；知道自己电脑的公网 IP（浏览器搜"我的 IP"） |

## 二、部署（约 3 分钟）

**1. 上传程序包**，在你的 Mac 上执行，把 `用户@服务器IP` 换成实际值：

```bash
scp "~/lnmp-panel/发布/lnmp-panel-amd64.tar.gz" 用户@服务器IP:/root/
```

**2. 登录服务器安装**，`你的公网IP` 换成你电脑的公网 IP，这是运维白名单，防止试错密码把自己封出面板：

```bash
ssh 用户@服务器IP
sudo -i
cd /root && mkdir -p lnmp && tar -xzf lnmp-panel-amd64.tar.gz -C lnmp
cd lnmp && OPS_CIDR=你的公网IP/32 bash scripts/install.sh
```

**3. 记下末尾打印的三行**：面板地址、用户名 admin、初始密码。忘了随时可以再看：

```bash
cat /etc/lnmp-panel/install.info
```

**4. 浏览器打开面板地址。** 证书是自签的，浏览器会警告，选"继续访问"。看到登录页就说明部署成功。

测完想重装系统就重装。不重装的话卸载：

```bash
cd /root/lnmp && bash scripts/uninstall.sh
```
