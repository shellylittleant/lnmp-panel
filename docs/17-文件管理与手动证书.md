# 17 文件管理与手动证书

> 记录日期：2026-09-17
> 状态：已确认（2026-09-17），作为阶段 9 交执行者

## 背景

需求方实测后提出两条刚需：建站后必须能进站点目录操作文件；证书除自动申请外必须能手动填入。第一条推翻 docs/09 中"文件管理器不做、只做上传下载插件"的决定，改为核心功能。

## 一、文件管理

### 范围（面向建站，不做通用文件浏览器）

| 功能 | 做法 |
|---|---|
| 浏览 | 任意层级进入目录，面包屑返回，显示大小、修改时间、属主、权限 |
| 上传 | 多文件与拖拽，单文件上限 2 GB，流式写临时文件再改名，成功后属主改为 www-data |
| 下载 | 单文件直接下载；目录打包成 zip 流式下载 |
| 删除 | 文件与目录，必须二次确认；禁止删除允许根本身 |
| 复制、移动、重命名 | 同一允许根内 |
| 新建目录、新建空文件 | |
| 解压 | zip、tar.gz 解压到当前目录，防 zip-slip（解压路径必须仍在允许根内），解压后属主改为 www-data。这是部署站点最常用的动作 |
| 压缩 | 选中文件或目录打成 zip |
| 在线编辑 | 1 MB 以内的文本文件，用 CodeMirror，保存即覆盖。配置文件、PHP 文件改一行不用来回传 |
| 权限 | 完整的权限对话框（2026-09-17 需求方要求）：三位数字模式加读写执行九宫格勾选，属主与属组从系统用户列表选择（默认列出 www-data、root），可勾选"应用到子目录与文件"递归生效。设 777 或属主改为 root 时给出提示但不阻止。每次修改写审计 |
| 搜索 | 当前目录按文件名过滤，不做全盘搜索 |

**不做**：WebSSH、全盘浏览、回收站。

### 允许范围（已确认：全目录）

需求方决定：整个文件系统都可以浏览和操作，面板面向有基础素养的运维人员，不做小白保护。

唯一例外：面板自己的密钥目录 `/var/lib/lnmp-panel/secrets`、面板数据库 `panel.db` 及其 WAL 文件、`/etc/lnmp-panel` 下的引导配置，不允许通过网页删除、编辑、下载、改权限。原因是删了面板就废了，私钥经网页下载没有必要。这几个文件要动走 SSH。其余任何路径不限制。

打开"文件"菜单默认落在 `/var/www`，可以直接改路径或逐级上溯到根。

### 入口（已确认）

主菜单增加第十项"文件"，打开即在 `/var/www`，顶部有站点快捷跳转。站点详情页增加"打开目录"按钮，直接跳到该站点根。

### 安全要求（执行者必须做到）

- 路径规范化后再判断是否命中上述例外；软链接解析到例外路径同样拒绝。
- 每个写操作（上传、删除、移动、解压、编辑、改权限）写审计，记录路径。
- 删除、覆盖、解压覆盖同名文件都要二次确认。
- 上传与解压完成后默认属主 www-data、目录 755、文件 644；之后由用户通过权限对话框自行调整。
- 目录 zip 下载与解压都流式处理，不整份读进内存。
- 现有的 filexfer 插件退役，功能并入核心；插件框架保留。

## 二、手动填入证书

站点详情的证书区增加"手动填入"：

| 项 | 做法 |
|---|---|
| 输入 | 两个文本框粘贴证书链 PEM 与私钥 PEM，或直接上传两个文件 |
| 校验 | 能解析；私钥与证书匹配；证书域名覆盖站点域名，不覆盖只警告不阻止；已过期拒绝 |
| 保存 | 写到与自动证书相同的位置，`certificates` 表 `issuer=manual`，到期时间取自证书 |
| 续期 | 手动证书不参与自动续期；到期前 30 天在概览与站点页提示 |
| 切换 | 站点可从手动证书切回自动申请，反之亦然 |
| 迁移与热备 | 手动证书随现有证书目录同步，无需额外处理 |
