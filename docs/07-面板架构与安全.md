# 07 面板架构与安全

> 记录日期：2026-09-16
> 状态：由我决定的方案，已按"安全第一"原则定

## 技术选型

| 层 | 选择 | 理由 |
|---|---|---|
| 后端 | Go | 单文件二进制，无运行时依赖，`systemd` 一个服务 |
| 前端 | Vue 3 + TypeScript，构建产物嵌入二进制 | 交付仍是一个文件；Vue 生态对表单密集型界面友好 |
| 存储 | SQLite（内嵌） | 无额外服务 |
| 部署 | 一条安装脚本 | 下载二进制、写 systemd unit、初始化管理员 |

## 安全设计（安全第一）

1. **运行身份**：面板以 root 运行（管理系统必须），但所有对外接口默认拒绝，只放行已认证请求。
2. **传输**：面板自带 HTTPS，首次启动生成自签证书，可换成站点证书。不提供 HTTP 明文模式。
3. **端口**：安装时随机生成高位端口，不用固定默认端口。
4. **入口路径**：登录页带随机安全路径前缀，扫描器直接访问根路径得到 404。
5. **鉴权**：单管理员账号，强密码策略，支持 TOTP 二次验证（建议开启），登录失败自动锁定与封禁来源 IP。
6. **访问限制**：可设置只允许特定 IP 段访问面板；可切换为"只监听本机、通过 SSH 隧道访问"模式。
7. **会话**：短有效期、绑定 IP、可随时踢出。
8. **操作审计**：所有写操作记录审计日志，不可从面板删除。
9. **自我保护**：防火墙模板默认包含面板端口与 SSH 端口的放行规则，防止用户把自己锁在外面；应用规则前做连通性确认，超时自动回滚。

## 多机预留

一个面板管一台机器。为后期"主控面板接入其他面板"预留：所有功能通过内部 API 实现，界面只调 API。将来主控只需代理调用各从面板的 API，不需要改功能代码。

## 开源与商业化

代码开源，许可证在首次公开发布前决定。提示：若保留商业化空间，需在 AGPL、Apache 2.0、源码可见但限制商用（如 BSL）之间取舍，这会影响他人贡献意愿，届时再议。
