### 5.2 Ubuntu 24.04 容器（PHP，原生架构；本机 OrbStack 为 arm64）

```bash
export PATH="$HOME/.orbstack/bin:$PATH"
cd work/grok
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -o bin/lnmp-panel-linux ./cmd/lnmp-panel
docker run --rm -v "$PWD:/src:ro" ubuntu:24.04 bash /src/scripts/verify-stage3-ubuntu.sh
```

期望：末行 `STAGE3_UBUNTU_OK`；`HTTP82=200 8.2.x` 与 `HTTP83=200 8.3.x`；ini/pool 权限 644；库名注入 400。arm64 上会出现 `MYSQL_OFFICIAL_NOT_RUNNING`（官方源无包）。脚本 **umask 077**，**不**手动执行 nginx/php-fpm/mysqld。

不要挂宿主机 `docker.sock`。
