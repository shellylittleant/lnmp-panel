### 1.1 冻结的插件接口

`internal/plugin`：

| 项 | 落点 |
|---|---|
| `Plugin` | `ID/Name/Version/Hooks/Routes/Pages/OnStart/OnStop` |
| `Route` | 相对 `/api/v1/plugin/<id>/`，带 `Handle` |
| `Page` | 声明式 `FormSchema`（字段 + 动作），可选 `StaticDir` |
| `Context` | WWW、数据目录、密钥目录、Settings、插件 config；不给 `*sql.DB` |
| 钩子 | `menu.register`、`site.php_versions`、`nginx.snippets`、`template.official`、`scheduler.register`、`site.after_save`、`firewall.sets`、`settings.section`。失败 recover，错误挂在插件列表 |
| 路径 | `plugin.Confine`：禁止 `..`、绝对路径、越出允许根；拒绝 `/etc/lnmp-panel`、`/var/lib/lnmp-panel` |

`work/grok/docs/05` 改为冻结说明。第三方短文：`plugins/README.md`。

### 1.2 build tags 与运行时启停

| tag | 行为 |
|---|---|
| （无） | 只编核心。`plugins/register.go` 无 tag |
| `plugin_filexfer` 或 `plugin_all` | 编入 `plugins/filexfer` |

`cmd/lnmp-panel` 空白 import `lnmp-panel/plugins`。`plugins` 表 `enabled`：0 则不 `OnStart`、不挂路由与页面。发布构建 `scripts/build.sh` 使用 `-tags plugin_all`。

HTTP：`GET /plugins`、`PUT /plugins/:id {enabled}`。插件路由 `/api/v1/plugin/<id>/...`。停用后该 API 与对应前端路径（filexfer 为 `/files`）HTTP **404**。

### 1.3 官方插件 filexfer

| 项 | 值 |
|---|---|
| ID | `filexfer` |
| 能力 | 列出允许根下一层、上传覆盖、下载 |
| 允许根 | 仅 `Context.WWW()`（生产 `/var/www`） |
| 上传后 | `chmod 644`，`chown www-data`（无该用户则跳过，便于非 Ubuntu 单测） |
| 禁止 | `..`、绝对路径、面板数据目录与 `/etc/lnmp-panel` |
| 不做 | 在线编辑、chmod/chown API、删树、解压、WebSSH |

### 1.4 界面（docs/14）

设置 → 环境安装 → **插件** 块：启停开关；filexfer 启用时「打开文件上传下载」进 `/files`。主菜单仍九项，无独立插件菜单。`/plugins` 仍重定向到环境安装。

`site.php_versions` 钩子已接到 `GET /php/versions`（无插件时行为不变）。
