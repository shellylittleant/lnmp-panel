> 无手机热点，通过清空/移出 OPS 白名单模拟非白名单源；锁死后 SSH `lnmp-panel whitelist clear` / `whitelist set` 恢复。

具体步骤：

2. 本机 `curl` 对登录 API 连续错误密码：第 1–5 次 `unauthorized`；**第 6 次** `{"code":"locked","message":"该 IP 已锁定至 2026-09-17T00:23:28Z"}`。
3. **立即**恢复：`lnmp-panel whitelist set 0.0.0.0/0,127.0.0.1/32,::/0`。
4. 127.0.0.1 仍处 IP 锁（约 30min）时，正确密码亦返回 locked；测试中用 `DELETE FROM ip_locks` + `kill -9` 自愈恢复管理员可登（**未动 SSH**）。

## 仍见 / 残留产品问题（简要）

1. **`use-template` 与 PHP 模板切换**：原文模式后需显式指定官方 PHP 模板 id；仅清 `raw_mode` 可能不够（Round1 已报，本轮靠 `nginx_template_id=11` 绕过）。
2. **默认 `index.html` 优先于 `index.php`**：phpinfo 验证需移开欢迎页。
3. **reboot 后面板 hang（Round1 5.10）**：本轮 1.6 **未复现**（前缀直接 200）；仍建议关注单连接 SQLite / WAL 场景。
4. **运维白名单极易误伤**：仅写盒子/历史 IP 会导致用户 Mac 403；测试/交付期建议临时 `0.0.0.0/0` 或明确登记用户出口。
5. **IP 锁定与白名单正交**：恢复白名单后，锁定 IP 在窗口内仍无法登录，需等过期或清 `ip_locks`（运维文档可补「SSH 清锁」）。
