### 5.2 Ubuntu 24.04 容器（防火墙，必须带 NET_ADMIN）

```bash
export PATH="$HOME/.orbstack/bin:$PATH"
cd work/grok
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -o bin/lnmp-panel-linux ./cmd/lnmp-panel
docker run --rm --privileged --cap-add=NET_ADMIN --cap-add=NET_RAW \
  -v "$PWD:/src:ro" ubuntu:24.04 bash /src/scripts/verify-stage4-ubuntu.sh
```

脚本：`umask 077`；占位进程听 22；保存并应用含 SSH/面板的规则后确认；再应用「丢弃新连接」的原文且**不确认**；观察到新连接失败（`LOCKOUT_OK`）；等 65 秒后面板 HTTPS 与 22 端口恢复（`ROLLBACK_OK`）。末行 `STAGE4_UBUNTU_OK`。

不要挂 `docker.sock`。无 `--privileged`/`NET_ADMIN` 时 `nft -f` 会失败。
