## 5. 编号建议给 Grok 的调整项（可执行）

### 阻塞 / 安全（建议进第三轮前修）

1. **【S1 阻塞】`GET /api/v1/files/zip` 绕过 G1**  
   对 `/var/lib/lnmp-panel`（及含子树敏感文件）应与 delete/copy/move/compress 同一套拒绝逻辑；至少不得打包 `tls/sites/*/privkey.pem`、`tmp/*.sql`、以及任何 secrets。  
   复现：登录后 `GET /files/zip?path=/var/lib/lnmp-panel` → 200 且 zip 内含站点私钥与 `ha-mysql.sql`。

2. **【S2】禁止路径的 zip 应返回 403**  
   对 `panel.db` / `panel.key` / `secrets` 等，zip 现返回空 zip 200；应与 download/read 一致 `forbidden`。

3. **【S3 策略】明确站点私钥是否允许文件管理读写**  
   若允许管理员备份：文档写明。若不允许：将 `/var/lib/lnmp-panel/tls/`（或至少 `**/privkey.pem`、panel 证书密钥）纳入与 panel.key 相同黑名单，且 zip 递归跳过。

### 产品 / UX（可不阻塞出包，建议同轮修）

4. **upload 的 `path` 语义**  
   传入「文件全路径」时会创建同名目录再上传；应校验：若 path 已存在且为文件 → 错误；或支持 `path`=目标文件路径。

5. **write 1MB 边界与错误文案**  
   content 恰 1MiB 因 JSON 外壳触发「请求格式错误」，易误解。建议：按 content 长度限制并返回「超过 1 MB」；或限制改为「请求体 ≤1MB+余量」。

6. **list 父目录是否隐藏敏感名**  
   `/var/lib/lnmp-panel` list 仍展示 panel.db/secrets 文件名。可选：过滤显示或标红不可操作。

### 历史仍建议（非本轮引入）

7. OPS 白名单：配置页强提示「勿只写盒子 IP」；或支持「当前客户端 IP 一键加入」。  
8. `systemctl restart lnmp-panel`：缩短 WriteTimeout 或延长 Shutdown 超时，避免 5s deadline。  
9. `use-template`：清 raw_mode 时自动回到官方 PHP/静态模板，勿留无 PHP conf。  
10. 欢迎 `index.html` 与 `index.php` 优先级：建站 PHP 模板时默认 index 顺序或文档说明。  
11. 迁移缺件提示：按**站点实际 php_version** 提示，勿因源机多装 8.2 误报。
