## 2. 未完成与原因

- **未在 Ubuntu 24.04 容器里跑 install.sh + systemd。** 本机 macOS arm64，无 Docker/OrbStack/Lima/colima。OS 检查、Docker 拒绝、安装脚本逻辑用夹具和代码路径覆盖；HTTPS/登录用本机 `--skip-os-check` 跑通过。审核者请按第 5 节在 Ubuntu 上再跑一遍安装。
- **阶段 1 不改监听地址热生效。** 改 `bind_mode` 后需调用 `/panel/restart`（systemd 再拉起）。`panel.json` 的 listen 主机名尚未随 bind_mode 自动改写，阶段 1 重启后仍用 bootstrap 时的 listen。若要从公网改成仅本机，需要改配置里的 listen 再重启。记入「需要决策」第 1 条。
- **官方 nginx 模板正文没有。** 按阶段划分属于阶段 2。
- **`--skip-os-check` CLI。** 仅方便测试，安装脚本不使用。生产机不要加这个参数。
