## 3. 与文档的偏离

| 点 | 说明 |
|---|---|
| 阶段 5 立刻执行走 `RunAbs` | 需求方决定立刻执行与到点执行统一为 `/bin/sh -c`，并点名推翻阶段 5 审核里把立刻执行限制为不经 shell 的做法。名称里的换行和 `#`、五段表达式范围，仍然拒绝 |
| 备机上的 PHP / ini / pool | 原先写接口是 `requireMaster`。按本阶段结论，环境安装是本机独立配置，这些接口改为已登录即可。站点、数据库、文件、定时任务的写接口仍然是备机 409 |
| 站点落库时机 | 意见书写的是 `nginx -t` 通过后再落库。实现是 `-t` 和 reload 都成功才落库；reload 失败时磁盘恢复、库不动。避免「库已是新的、进程仍是旧的」 |
| 压缩覆盖 | 为让确认框真的挡住覆盖，`Compress` 增加 `confirm`。不确认时目标已存在返回已有错误「目标已存在，请确认覆盖」，不是新的业务规则 |
| 意见书 H4 的 CLONE 语句 | 不修语法，删除未使用路径 |
| 意见书 H6 的两个选项 | 按需求方选择：不把防火墙、白名单、监听模式、环境安装收成主机同步项 |
