## 1. 完成内容

对照 `docs/11` 阶段 6、`docs/04`、`work/grok/docs` 00 §8.3、01 migrate、03 表、04 API。

### 1.1 配对令牌含 TLS 指纹

| 要求 | 落点 |
|---|---|
| B 生成一次性令牌 | `POST /migrate/token`。明文 `<证书 SHA-256 十六进制前 16 位>.<32 hex 随机>`，TTL 15 分钟，库中只存 `sha256(令牌)` |
| A 先校验指纹再发令牌 | `POST /migrate/connect`：拨号取 B 证书指纹，前 16 位与令牌首段不符则中止，**之后**才 `POST /migrate/accept` |
| 长期钉死完整指纹 | 握手成功写入 `peers.fingerprint`；之后对端 HTTPS 用 `VerifyPeerCertificate` 比对完整指纹 |

### 1.2 临时 SSH 钥

A 在 `/var/lib/lnmp-panel/secrets/migrate-key` 生成 ed25519。公钥交给 B，B 写入 `/root/.ssh/authorized_keys` 的 `# LNMP-PANEL-MIGRATE-BEGIN/END` 段。A 把 B 主机钥写入 `migrate-known_hosts`（主机名与 `[host]:port` 两行，**不含面板端口**），rsync 使用 `StrictHostKeyChecking=yes` + `IdentitiesOnly=yes` + `BatchMode=yes`。

### 1.3 目标机预检

`POST /migrate/preflight`（A 调 B `POST /migrate/peer/preflight`）：Ubuntu LTS 窗口、磁盘（需预留 1GB+1GB）、MariaDB 则拒绝、Apache 占用 80/443 则拒绝。PHP/MySQL 在支持的 Ubuntu 上认定可按面板流程安装。预检顺带 `EnsureLayout` 与 tmp 目录。

### 1.4 全量与增量

`POST /migrate/start {mode: full\|incr}`。流程相同（rsync 天然增量）：预检 → rsync `/var/www`、证书目录、nginx conf.d 与 sites-available、my.cnf、acme.key → 若本机有 mysqld 则 `mysqldump --all-databases` 再 rsync → HTTP `POST /migrate/peer/apply` 提交元数据 bundle（32MB 上限）。

Bundle：用户模板（按内容哈希映射 ID）、站点与域名跳转、证书 PEM、PHP ini/pool 与 `php_versions` 行、MySQL 库/用户元数据、防火墙规则文件、nginx 全局片段、面板保留天数设置。不复制管理员密码与运维白名单。

### 1.5 作废钥

`POST /migrate/cancel`：停任务、删 A 的 migrate-key / known_hosts、去掉 authorized_keys 段、通知 B `POST /migrate/peer/cancel` 删令牌与授权钥。

对端 `accept` / `peer/*` **不走 Cookie/CSRF**，用配对令牌；`withSecurity` 对这些路径跳过 IP 白名单（令牌即密钥）。

### 1.6 PHP：切到 PHP 后 index.php 优先于 index.html

真机 3.3 待观察项：站点根同时有 `index.html` 与 `index.php` 时 `/` 应进 PHP。

| 项 | 处理 |
|---|---|
| 官方 PHP 模板 | `index index.php`（不再列出 html）；`location = / { rewrite ^ /index.php last; }`；`try_files $uri /index.php?$query_string`（去掉 `$uri/`） |
| 切 PHP 换模板 | `site.autoPHPTemplate`：官方「静态站点」↔「PHP 站点」随 `php_version` 设置/清空切换 |
| 容器确认 | 同时写 `HTML_MARKER` 的 index.html 与 PHP 的 index.php，切 8.3 后 `GET /` 为 **502**（unix socket 不存在），error.log 为 `fastcgi://unix:/run/php/php8.3-fpm.sock`，**不是** 200 HTML_MARKER |

前端 `/migrate`：生成令牌、填地址配对、预检、全量/增量、取消、进度轮询。版本号 `0.1.0-stage6`。
