```bash
  local st=""
```

```bash
EOF

curl -sk -c /tmp/cj -b /tmp/cj -X PUT -H 'Content-Type: application/json' \
  -H "X-CSRF-Token: $CSRF" --data-binary @/tmp/bad.json "$API/firewall/raw"
curl -sk -c /tmp/cj -b /tmp/cj -X POST -H 'Content-Type: application/json' \
  -H "X-CSRF-Token: $CSRF" -d '{}' "$API/firewall/apply"
# 不要 confirm
sleep 65
ss -lntp | grep ":${PANEL_PORT}"
curl -sk -o /dev/null -w '%{http_code}\n' "https://127.0.0.1:${PANEL_PORT}/${PANEL_PFX}/"
# 期望 200
nft list ruleset | grep -c 'tcp dport 22 drop' || true
# 期望 0（回滚后不应残留显式 drop）
```

SSH 从你的电脑再连一次，必须还能上。

### 11.3 窗口内杀服务，systemd 拉起后自动回滚

再 apply 一次 `/tmp/bad.json`（不要 confirm），然后：

```bash
systemctl kill -s SIGKILL lnmp-panel.service
# systemd Restart=always 会拉起；RecoverPending 在监听前执行
sleep 4
systemctl is-active lnmp-panel.service   # active
curl -sk -o /dev/null -w '%{http_code}\n' "https://127.0.0.1:${PANEL_PORT}/${PANEL_PFX}/"
# 200
nft list ruleset | grep 'tcp dport 22 drop' && echo FAIL_DROP_LEFT || echo RECOVER_OK
```

重新登录后：

```bash
# 确认 pending 已空（GET /firewall 的 pending 为 false）
curl -sk -c /tmp/cj -b /tmp/cj "$API/auth/login" -H 'Content-Type: application/json' \
  -d "{\"username\":\"admin\",\"password\":\"你的密码\"}"
# …取 CSRF 后
curl -sk -c /tmp/cj -b /tmp/cj "$API/firewall" | grep -o '"pending":[^,]*'
# 期望 "pending":false
```
