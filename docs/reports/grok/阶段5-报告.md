### 1.1 日志查看、统计、跟随、logrotate

| 要求 | 落点 |
|---|---|
| 多来源查看 | `GET /logs/sources`：journald、auth、syslog、kern（防火墙丢包）、nginx access/error、各站点 access/error、php-fpm、MySQL error/slow |

| 统计 | `GET /logs/stats`：access 的 PV/UV/状态码/URL/IP/Referer/UA/平均响应时间；SSH 失败次数；慢 SQL 排行。小时桶写入 `log_stats_hourly` |
| logrotate 接管 | 官方模板 `logrotate/面板默认` → `/etc/logrotate.d/lnmp-panel`。`GET/PUT /logs/rotate` 表单（保留天数、maxsize）+ 原文；漂移 409，需 `force` |

前端 `/logs`：来源下拉、查询、跟随、统计、logrotate 原文。
